Welcome to the repository for my personal portfolio website! This project is a modern, fully responsive, and highly interactive web application designed to showcase my skills, projects, and professional experience as a Software Developer.

## 🌟 Overview

The website leverages **React** for a robust component-based architecture, **Tailwind CSS** for sleek, responsive, and maintainable styling, and **Framer Motion** to deliver smooth animations and interactive transitions that elevate the overall user experience.

It is optimized for all screen sizes, ensuring a seamless and beautiful browsing experience whether you're on a desktop, tablet, or mobile device.

## ✨ Features

- **Dynamic Hero Section:** Engaging landing banner with animated background elements and a professional portrait.
- **Interactive UI/UX:** Smooth scrolling, premium glossy hover effects, and micro-animations on all interactive elements.
- **Project Showcase:** Detailed cards for projects featuring modern, polished UI elements.
- **Skills & Experience:** Organized layout highlighting technical expertise and a professional timeline.
- **Mobile-First Design:** Fully responsive navigation sidebar, flexible grid systems, and touch-optimized interactive elements.
- **Contact Form:** Integrated professional contact section for easy communication and quick access to social links.

## 🛠️ Tech Stack

| Technology | Description |
| :--- | :--- |
| **React (v18)** | Frontend UI library for building dynamic interfaces |

## 🚀 Installation & Setup

Want to run this project locally? Follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Pratik-Bavche/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   # or
   npm start
   ```

4. **Open in browser:**
   Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
